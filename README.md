# LASU Alumni WordPress Theme — Version 2.0.0

A minimalist, **fully responsive**, lightweight WordPress theme for the **Lagos State University (LASU) Alumni Association**.

## What's New in v2

- Fully responsive design that adapts to all device sizes (mobile, tablet, desktop)
- Mobile hamburger menu with smooth toggle
- Improved typography using `clamp()` for fluid sizing
- Better touch targets and spacing on small screens
- **Demo content** automatically created on theme activation (sample pages + news posts)
- Version bumped to 2.0.0

## Features

- LASU logo color scheme: Gold (#FCBF29), Blue (#0089E2), Dark (#24211C)
- Fast-loading (system fonts, minimal CSS, no page builders)
- Homepage with multiple sections: Hero, What We Offer, Latest News, Events, Membership Benefits, Alumni Spotlight, Get Involved
- Custom logo, primary menu, featured images support
- GPL licensed

## Installation

1. Download/clone this repository.
2. Zip the folder and upload via **Appearance → Themes → Add New → Upload Theme**.
3. Activate the theme — demo pages and posts are created automatically.
4. Set a custom logo and Primary Menu (Appearance → Menus / Customize).
5. Create or edit pages as needed (Membership, Events, etc. already seeded).

## Recommended Setup

- Assign the Primary Menu
- Optionally set a static front page or leave as latest posts
- Publish additional posts to expand the Latest News section

## Customization

Edit CSS variables in `style.css` and homepage sections in `index.php`.
